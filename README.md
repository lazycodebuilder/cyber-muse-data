# cyber-muse-data
Training data for the cyber-muse project (Qwen3-4B cybersecurity distillation).
- `training_dataset.jsonl.gz` — 3308 Q&A pairs (gzipped JSONL)
- `eval_questions.json` — 50 sealed benchmark questions
- `scripts/` — training/benchmark pipeline scripts
- `config.toml` — Heretic ablation config
